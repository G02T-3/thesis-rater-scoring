# NWUFPA Matrice 4T trial scoring

Offline scoring page for Tian Gorrie's NWUFPA Matrice 4T veld fire reconnaissance trials (Stenden South Africa).

This repository holds only the blank scoring web app (run codes, questions and score anchors). It does not contain rater names or any scores. Scores stay on each rater's phone until they export a file to Tian.

Open the hosted page once with a signal, then add it to the home screen. After that it works without a signal.
