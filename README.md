# NWUFPA Matrice 4T trial scoring

This is the offline scoring page for my NWUFPA Matrice 4T veld fire reconnaissance trials (Stenden South Africa).

This repository holds only the blank scoring web app (run codes, questions and score anchors). It does not contain rater names or any scores. Scores stay on each rater's phone until they export a file and send it to me.

You will need the access code I gave you. Please use that code only on your own phone.

Please open the hosted page once with a signal, then add it to the home screen. After that it works without a signal.

Tian Gorrie, Stenden South Africa, thesis trial
